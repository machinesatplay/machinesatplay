# machines at play

mach is an open source engine and cli for building multiplayer 3d browser games with bevy.

## get started

[**give to your coding agent**](https://machinesatplay.com/agent-prompt.md)

or:

```sh
curl --proto '=https' --tlsv1.2 -LsSf https://machinesatplay.com/install.sh | sh
mach new my-game
cd my-game
mach dev
```
